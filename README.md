# ScrapeBot — Type B Demo (Web Scraper + Data)

## Overview
Working web scraper demo that collects product listings from public demo sites and exports them as structured CSV/JSON data. 20 real product records included.

- `scraped_products.csv` — 20 scraped product records in CSV format
- `scraped_products.json` — 20 scraped product records in JSON format
- `index.html` — Public demo page with data table and code preview
- `styles.css` — Demo page styling
- `architecture.md` — Component diagram and data flow
